# One Piece official English reference sync

`[sync_onepiece_gallery.py](../scripts/sync_onepiece_gallery.py)` discovers the English One Piece catalog from Bandai's public card-list HTML. It reads the live `select#series` options, requests each selected series, and parses the official `dl.modalCol` records, exact modal IDs, card names, and image `data-src` values. It does not construct image filenames from card-number ranges. Official `_pN` artwork records remain separate identities, for example `onepiece:en:OP01-001_p1`.

Run with `.env/bin/python scripts/sync_onepiece_gallery.py`. To limit discovery and acquisition, pass `--sets OP12 OP01`. The default staging path is `runs/card_recognizer/onepiece_catalog_sync/`; `--catalog-only` records catalog coverage without downloading. The output is isolated from `datasets/card_recognizer/cards/` and is not automatically promoted into training. Repeated runs resume from the manifest and valid staged files. `--max-download-bytes` sets the per-run transfer cap (default 1 GiB), `--max-downloads` limits a pass, and `--workers` is capped at three.

`manifest.json` records the official series label/value, exact catalog ID and name, language, source catalog/image URLs, staging path, image SHA-256, detected format and dimensions, byte count, and status. `present_local` means an image with that exact filename stem was already found in the local card corpus; it does not assert that its bytes match the current Bandai asset. `unavailable`, `deferred_budget`, and series-level failures remain explicit. The manifest's discovery count is only the set of records returned by the selected live series HTML, not a claim about cards absent from Bandai's selector or other languages.

All downloaded assets are official digital references, not independent camera captures. Public availability does not establish additional reuse rights. Keep English and Japanese language identities separate, preserve existing source images, and do not silently replace watermarked stock with Japanese cards or generated restorations. The collector preserves source assets unchanged and performs no watermark removal, OCR labeling, card-crop labeling, or canonical-gallery mutation. A catalog record is an auditable reference candidate; exact physical variant identity for a binder crop still requires separate visual verification.
